# 対応エリアの地図

`public/images/fukuoka-city-map.svg` は、福岡県の輪郭の中で福岡市だけをブランドカラーで強調した説明用の地図です。

- 出典：国土交通省「国土数値情報（行政区域データ）」2026年1月1日時点
- データ：`N03-20260101_40_GML.zip` 内の GeoJSON
- 配布ページ：<https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N03-2026.html>
- 使用許諾：[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

## 加工内容

福岡県内の行政区域を統合して県の輪郭を作成し、`N03_004` が `福岡市` の区域を統合して強調表示しています。東区・博多区・中央区・南区・城南区・早良区・西区の7区が含まれることを確認しています。

境界座標は0.00001度の精度にそろえて統合し、県の輪郭は0.0012度、市の輪郭は0.0008度の許容誤差で簡略化しています。480×420の表示範囲で面積0.5平方ピクセル未満の微小な区域は描画を省略しています。緯度33.5度を基準に経度方向を補正し、県と市に同じ縮尺・位置を使用しています。

地図は位置関係を示すイラストで、路線・駅・移動経路を表しません。表示時は `AreaSection.astro` の画像代替テキストと出典表記も維持してください。
